# Online Fraud Fighter Team — 50-Article Blog Edition

This package adds 50 educational cryptocurrency-fraud articles to the existing website.

## Files
- `index.html` — main website
- `blog/index.html` — blog directory
- `blog/*.html` — 50 individual articles

## Comments and reviews
The articles are prepared for **Giscus**, which uses GitHub Discussions so visitors can comment and react without the site needing its own database.

Before publishing, replace these three placeholders in every article with the values from https://giscus.app/:
- `YOUR-GITHUB-USERNAME/YOUR-REPOSITORY`
- `YOUR_REPOSITORY_ID`
- `YOUR_CATEGORY_ID`

The GitHub repository must be public and have Discussions enabled. In Giscus, choose the repository, enable the desired Discussion category, then copy the generated script settings into the articles.

## Important
These articles are educational and do not guarantee cryptocurrency recovery. Visitors should never post passwords, seed phrases, private keys, or authentication codes in comments.
