# Comments setup

The blog pages include a placeholder for comments. To enable live comments with Giscus:

1. Create/choose a public GitHub repository for the website.
2. Enable GitHub Discussions in that repository.
3. Install/enable the Giscus GitHub App for the repository.
4. Generate the Giscus script configuration for the repository at https://giscus.app/.
5. Replace the placeholder comment block in the blog templates with the generated Giscus script.

Do not ask commenters to post seed phrases, private keys, passwords, or authentication codes.
